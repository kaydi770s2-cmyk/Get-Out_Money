# ⚡ โปรแกรมบัญชีรายรับ - รายจ่าย (Expense Tracker)

เว็บแอปพลิเคชันสำหรับบันทึกและจัดการรายรับ-รายจ่ายส่วนบุคคล ออกแบบด้วยธีม **Dark Cool Anime Mode** หน้าตาทันสมัย สบายตา และรองรับการทำงานแบบ Real-time

🌐 **ทดลองใช้งานหน้าเว็บ (Live Demo):** [คลิกที่นี่เพื่อใช้งาน](https://kaydi770s2-cmyk.github.io/Get-Out_Money/)


## ✨ คุณสมบัติเด่น (Features)

1. 🏷️ **หมวดหมู่รายการ:** เลือกประเภท (รายรับ/รายจ่าย) และหมวดหมู่พร้อมไอคอน (🍔 อาหาร, 🚗 เดินทาง, 🛍️ ช้อปปิ้ง, 💰 เงินเดือน, 📌 อื่นๆ)
2. 🔍 **ค้นหา Real-time:** กรองและค้นหารายการประวัติได้ทันทีขณะพิมพ์ โดยไม่ต้องกดปุ่มค้นหา
3. 📜 **ประวัติรายการ:** แสดงลำดับ ID, ประเภท, หมวดหมู่, ชื่อรายการ และจำนวนเงินอย่างเป็นระเบียบ
4. 📊 **สรุปยอดเงินอัตโนมัติ:** คำนวณรายรับรวม รายจ่ายรวม และยอดคงเหลือสุทธิให้อัตโนมัติ
5. 🗑️ **ระบบล้างข้อมูล:** ปุ่มล้างประวัติทั้งหมด พร้อมระบบยืนยัน (`confirm()`) เพื่อป้องกันการกดลบโดยไม่ได้ตั้งใจ

---

## 🛠️ เทคโนโลยีที่ใช้ (Technologies Used)

* **HTML5:** โครงสร้างเว็บและฟอร์มรับข้อมูล
* **CSS3:** สไตล์ Dark Mode, Flexbox และ SVG Mascot อนิเมะแบบเคลื่อนไหว
* **JavaScript (Vanilla JS):** จัดการ DOM คำนวณยอดเงิน และกรองข้อมูลแบบ Real-time
